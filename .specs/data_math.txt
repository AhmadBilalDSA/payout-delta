GROSS-UP MATH ENGINE (lib/calculatorEngine.ts)
================================================================================

PURPOSE: Given target net local deposit, compute exact gross USD invoice.

-- MAIN EXPORT --

calculateGrossFromTargetNet(input: GrossUpInput): GrossUpResult

  Input (GrossUpInput):
    targetNetLocal        number   — desired net in domestic currency
    platformFeePercent    number   — platform commission 0-100 (e.g. Upwork = 10)
    channelSpread         number   — FX spread decimal 0-1 (e.g. Wise = 0.0045)
    baseRate              number   — interbank rate (domestic units per 1 USD)
    fixedFeeUSD           number   — flat clearing fee in USD
    intermediaryCutUSD    number   — SWIFT correspondent cut in USD
    landingFeeLocal       number   — local receiving fee in domestic currency
    taxWithholdingRate    number   — statutory withholding decimal 0-1

  Output (GrossUpResult):
    feasible              boolean  — false if inputs are degenerate
    realizedRate          number   — baseRate × (1 − spread)
    netUsdNeeded          number   — USD that must cross FX layer
    usdBeforeWires        number   — netUsdNeeded + all wire/bank cuts
    platformRate          number   — platformFeePercent / 100
    requiredGrossBill     number   — gross USD to invoice client
    platformCutUsd        number   — requiredGrossBill × platformRate
    bankAndWireCutUsd     number   — fixedFeeUSD + intermediaryCutUSD + landingFeeUsd
    spreadLeakageUsd      number   — netUsdNeeded × spread
    spreadLeakageLocal    number   — netUsdNeeded × baseRate × spread
    taxWithholdingLocal   number   — statutory withholding in domestic currency
    realizedTakeHomeLocal number   — always equals targetNetLocal (guaranteed)

  7-step closed-form formula:
    platformRate      = platformFeePercent / 100
    realizedRate      = baseRate × (1 − channelSpread)
    preTaxLocal       = targetNetLocal / (1 − taxWithholdingRate)
    netUsdNeeded      = preTaxLocal / realizedRate
    landingFeeUsd     = landingFeeLocal / baseRate
    usdBeforeWires    = netUsdNeeded + fixedFeeUSD + intermediaryCutUSD + landingFeeUsd
    requiredGrossBill = usdBeforeWires / (1 − platformRate)

  Guard rails (returns INFEASIBLE sentinel if triggered):
    targetNetLocal <= 0 OR baseRate <= 0
    platformFeePercent < 0 OR >= 100
    channelSpread >= 1
    taxWithholdingRate < 0 OR >= 1
    realizedRate <= 0

  Performance: O(1), single useMemo pass, INP < 50ms guaranteed
  Safety: All divisions via lib/safeMath.ts guards (safeDivide, safeMultiply)
          No Infinity, no NaN, no division-by-zero possible

-- SECONDARY EXPORTS --

rebaseFee(usd: number, unitsPerBase: number): number
  Converts a USD-denominated fee to another settlement currency.
  Constraint: unitsPerBase passed as a plain number (not imported from currency.ts)
              to keep engine self-contained for the edge-case harness.

rebaseRate(ratePerUsd, unitsPerUsdOfBase, unitsPerUsdOfQuote): number
  Converts a rate (destination units per USD) to units-per-settlement-currency.
  Formula: (ratePerUsd × unitsPerUsdOfQuote) / unitsPerUsdOfBase

SAFE MATH LAYER (lib/safeMath.ts)
================================================================================

safeDivide(a, b): number     — returns 0 if b === 0 or result is not finite
safeMultiply(a, b): number   — returns 0 if result is not finite

Used by: calculatorEngine.ts, all fee computation paths

CORRIDOR STATUTES ENGINE (lib/corridorStatutes.ts)
================================================================================

SERVER-ONLY module — client islands must NOT import this directly.

Exports:
  buildCorridorStatutes(corridors: Corridor[]): CorridorStatuteMap
  corridorStatute(corridor: Corridor): CorridorStatute | undefined

CorridorStatute projects per corridor:
  purposeCode             string   — statutory payment purpose code
  mandatoryRealizationCert boolean — whether FIRC/equivalent is required
  safeHarbourRule         string   — applicable safe-harbour description
  localRail               string   — local settlement rail identifier

Source data: jurisdiction + regulatory registries (NOT data/regulatoryBanking.ts directly)
Purpose: Keeps regulatory data server-side; client receives only the projected statute.

================================================================================
REFERENCE ID ALGORITHM (ExecutiveTreasuryReport)
================================================================================

Algorithm: FNV-1a (Fowler-Noll-Vo 1a) hash
Input: roster of rows (serialized deterministically)
Output: hex digest used as the report reference number
Constraint: No clock, no Math.random() — output is deterministic and reproducible.

Script: scripts/simulate_edge_cases.mjs
  Fuses calculatorEngine.ts + safeMath.ts + utils/calculateRoute.ts into plain JS.
  Tests: zero inputs, negative inputs, 100% fee, 100% spread, 100% tax,
         maximal values, corridor boundary conditions.
  Constraint: Engine imports must remain self-contained (no currency.ts import).
